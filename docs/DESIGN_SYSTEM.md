# 배민 블랙 디자인 시스템

- **핵심 경험:** 원본 배민 앱에 어울릴 만큼 절제된 보조 UI. 다른 앱의 버튼과 탐색에 개입하지 않고, 사용자에게 필요한 순간만 개인 기록을 전달.
- **관리 앱 위계:** 가게 검색 → 상태 필터 → 가게 목록 → 메모 타임라인. 불필요한 카드 중첩·설명 문구·장식 구분선 최소화.
- **색:** 경고는 선명한 붉은 계열, 주의는 호박색, 즐겨찾기는 별도 중립 강조. 의미색을 배경 전체에 넓게 칠하지 않음. 라이트/다크에서 대비 확보.
- **배지:** 작은 금지 아이콘 중심. 화면 요소를 겹치지 않는 위치에 놓고 긴 텍스트 배지나 독립 플로팅 버튼 느낌 금지.
- **오버레이:** 애니메이션은 없거나 짧은 페이드인. 스크롤과 위치 추적 애니메이션 금지. 오버레이는 기본적으로 비터치.
- **문구:** 상태와 다음 행동을 짧고 구체적으로. '등록됨', '메모 2건', '블랙리스트'처럼 사실 위주.
- **입력:** 사진·메모 입력 중 키보드가 저장/취소를 가리지 않게. 긴 메모에도 안정된 스크롤/저장.
- **컴포넌트:** Material 3와 Compose를 이용하되 기본 데모의 상투적 카드·색·아이콘 조합 그대로 사용 금지.
- **검증:** 작은 화면, 다크 모드, 글자 크기 증가, 화면 회전, 시스템 바 겹침, 길고 빈 데이터에서 실제 보임과 터치 가능성을 분리해 확인.

사용자가 승인한 배지 동작·구조를 디자인 실험 명목으로 변경하지 않는다.
