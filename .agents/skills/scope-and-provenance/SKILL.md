# Scope and provenance gate
우선순위: 현 사용자 요청 > 기존 승인 제품 계약/실제 사용 동작 > 관련 코드·데이터·서명 > 로컬 일반 지침 > 외부 스킬 추천.
- 수정 전 **이번에 변경할 동작**과 **변경하지 않을 화면/데이터**를 내부적으로 분리한다.
- 근거 라벨: 사용자 확정 / 코드 관찰 / 미승인 제안 / 미결정.
- 분석만 부탁받았다면 어떤 코드/설정도 수정하지 않는다.
- 버그 수정 명목의 전체 CSS 재배치, 문구 변경, 버튼 재배치, 불필요한 dependency 교체 금지.
- AI가 조용히 화면을 바꾼 다음 DESIGN.md/테스트 snapshot을 변경해 정답으로 만드는 순환 증명 금지.
- 발견한 다른 개선 사항은 본 범위에 넣지 않고 '추가 제안(미적용)'으로 간단히 설명.
- 더 나은 방법이 있으면 현재 사용자 목표·기존 계약을 보존하는 **최소 변경**으로 구현.
- 작업 완료 전 diff로 무관 영역/레이아웃 회귀 확인.
