# Evidence-based handoff
- 작업 전 이미 확인·수정한 부분과 남은 쟁점을 확인. 이전 대화의 검사·commit·로그를 존중.
- 직접 확인한 코드/테스트/화면/기기/Release URL **각각 구분**. 성공 주장 전 실제 출력 확인.
- 보고는 요청 결과, 변경 파일, 핵심 검증 명령과 결과, 실제 남은 제약, APK 링크(요청 시) 순.
- 권한 부족/장비 미연결이면 미실행·사용자 확인 항목만 간단히 명시, 허위 완료 금지.
- 단순 수정에 기나긴 보고서/추가 승인/프로토타입 제작 금지. 필요한 결정을 할 수 있으면 한 번에 수행.
- 회귀가 발견되면 원래 승인 상태로 되돌리는 방법을 제시하고, 요청하지 않은 변경도 솔직히 밝힌다.
