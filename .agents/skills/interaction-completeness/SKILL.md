# interaction-completeness

1. 가게/메모의 생성·수정·삭제, 상태 변경, 공유 수신, 사진 선택, 백업·복원에 실제 코드를 연결한다.
2. 긴 메모·키보드·작은 화면에서도 저장/취소가 보이고 터치 가능해야 한다.
3. 앱으로 재진입했을 때 기록·선택·스마트폰 상태가 이어진다.
4. 빠른 연타나 중복 공유에 따른 중복 등록을 방지한다.
5. 접근성 배지는 클릭을 가로채지 않고 배민의 스크롤/카드 선택을 막지 않는다.
