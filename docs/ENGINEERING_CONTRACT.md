# 구현·안정성 계약

- UI/데이터: Compose + ViewModel + Room. 데이터베이스를 단일 source of truth로 사용.
- 서비스: AccessibilityService는 배민 패키지 이벤트만 처리. Debounce/throttle과 이전 작업 취소, 노드 재활용·정리.
- 화면 구분: 목록/검색 결과/상세/지원되지 않는 화면. 불명확한 화면에서 전 화면 오버레이 재활용 금지.
- 매칭: shop ID/상호+지점/명시적 별칭 순서. 모호한 값은 미매칭으로 반환. 사용자 메모를 잘못된 매장에 보여주지 않음.
- 위치: 노드 `getBoundsInScreen()`; 좌표계·가시 영역·회전·분할 화면 확인; 카드 밖 좌표면 표시하지 않음.
- 배지: `TYPE_ACCESSIBILITY_OVERLAY`, 비포커스·비터치. 스크롤 시작 시 즉시 제거, 정지 후 현재 배지만 재구성.
- 상세 경고: 임시 UI와 관리 앱 기록 화면 연결. 임의로 배민 클릭을 실행하거나 결제에 개입하지 않음.
- 공유: `ACTION_SEND`의 텍스트를 입력 자료로 처리. 허용된 HTTPS 호스트만 선택적으로 따라가고 리디렉션 및 시간 제한.
- 로컬 저장: Room 테이블의 ID·FK·유니크 키·삭제 규칙. 사진 파일 정리와 ZIP 복원 검증.
- 데이터 안전: 최초 DB 생성 이후 자동 파괴적 마이그레이션 금지. 버전/서명 유지.
- UI 쓰레드: DB/링크 확인/ZIP 입출력을 Main에서 수행하지 않음.
- 외부 권한과 사생활: 필요한 접근성 서비스 권한만, 화면 텍스트/메모 외부 전송 금지.
