# 배민 블랙 — 확정 제품 계약

## 목적
배달의민족을 사용하는 중 과거 주문 경험을 잊지 않도록 가게별 개인 메모와 블랙리스트를 확인할 수 있는 독립 Android 보조 앱. 원본 배민 APK 수정 없음.

## 주요 사용자 여정
1. 처음 실행: 접근성 서비스 필요성을 설명하고 설정으로 이동. 권한이 없어도 가게 기록을 수동 작성할 수 있음.
2. 가게 등록: 배민 `ACTION_SEND text/plain` 공유 링크 또는 관리 앱 수동 등록. `shopDetail_shopNo`, `shopNo`, `shopNumber`는 *가능한 입력 파라미터*이며 모든 링크에 존재한다고 가정하지 않음.
3. 목록 탐색: 접근성 서비스에서 화면에 보이는 가게 카드와 이름/지점명을 식별. 정확히 매칭된 블랙리스트 가게에만 작은 비터치 배지 표시.
4. 스크롤: `TYPE_VIEW_SCROLLED` 즉시 배지 숨김. 마지막 스크롤 이벤트 180ms 후 노드·좌표를 **다시** 얻고 새 위치에 표시. 기존 배지를 끌고 다니지 않음.
5. 가게 상세: 정확히 매칭된 블랙리스트 가게의 경고, 그 밖에는 최소 메모 진입 UI. 가게 기록은 보고 추가·수정·삭제 가능.
6. 재방문: 모든 기록·분류·이미지·설정 유지. JSON+이미지 ZIP 백업 및 안전한 병합 복원.

## 데이터
- Shop: 내부 ID, 배민 shop ID(선택), 상호, 지점명(선택), 별칭, 공유 링크, 상태(NORMAL/CAUTION/BLOCKED/FAVORITE), 생성·수정 시각.
- Note: 내부 ID, 가게 ID, 날짜, 메뉴/제목(선택), 자유 메모, 평점(선택), 사진 참조(선택), 생성·수정 시각.
- 동일 shop ID는 중복 생성 금지. name-only 애매한 매칭은 자동 차단 금지.

## 시각적·상호작용 원칙
- 목록 배지는 작은 빨강 계열 금지 아이콘. 카드/가게명 안전 영역에 위치시키되 배민 터치를 가리지 않는다.
- 스크롤 중 배지가 어색하게 따라다니는 것보다 숨겼다가 정확히 나타나는 편을 선택.
- 상세 경고는 가게 페이지를 가리지 않는 작은 패널. 관리 앱은 가게 검색·필터·최근 기록 중심.
- 기록 편집에서 저장/닫기/뒤로가기를 확실히 제공하고 키보드와 시스템 바에 가려지지 않게 한다.

## 범위 밖
원본 APK 수정, 프록시·VPN 감청, 비공개 API 호출, 루팅·후킹, 검색 결과 항목 실제 삭제, 상시 OCR, 서버·계정·클라우드 동기화.

## 완료 판정
- 앱 코드 + 빌드 + 가게/메모 관리와 백업 로직 테스트로 코드 측 완료 판정.
- 배민 실기기의 실제 접근성 트리에서 카드 인식과 배지 위치/속도는 기기 사용 후 별도 확인; 미검증을 성공으로 기록하지 않음.

## 배민 블랙 고유 경험의 일곱 관점과 합격 조건

아래 관점은 범용 스타터의 핵심 품질 질문을 이 프로젝트에 실제로 적용한 것이다. 새로운 기능을 조사하거나 사용자에게 다시 선택받기 위한 목록이 아니다.

| 관점 | 배민 블랙에서의 구체적 의미 | 관찰 가능한 성공 |
|---|---|---|
| 주 행동과 성공 | 배달 앱에서 과거의 개인 평가와 차단 상태를 기억하게 함 | 등록·수정한 가게가 다음 방문에 동일하게 연결됨 |
| 인지·주의·리듬 | 원래 배민의 탐색·주문 흐름을 방해하지 않음 | 경고가 짧고 배지에 불필요한 애니메이션이 없음 |
| 상호작용·조작 | 배지 자체는 클릭/스크롤을 가로채지 않음 | 가게 목록의 원래 카드 터치와 스크롤이 정상 |
| 시간·연속성 | 앱 이탈, 잠금, 접근성 서비스 재연결에서 화면·기록이 일관됨 | 오래된 가게의 배지가 다른 화면에 남지 않음 |
| 데이터·신뢰 | 가게명만 같다고 다른 지점에 잘못 경고하지 않음 | 모호한 매칭은 표시 생략; 가게 ID 우선 |
| 환경·접근성 | 작은 화면·큰 글씨·다크 모드·키보드·권한 거부 상황 | 필수 CRUD/저장/복귀가 가려지지 않고 권한 없이도 메모 관리 가능 |
| 제품 고유성 | 원본 앱처럼 그럴듯한 장식보다 실제로 확실한 개인 기록 제시 | 목록은 소형 배지, 상세는 필요한 경고만 제공 |

### 정보 구조와 말투

- 처음 진입: 접근성 활성화 상태와 기록 검색을 한눈에 확인. 설명은 필요한 순간에만.
- 반복 작업: 가게 등록, 분류 변경, 메모 조회·추가를 간결한 진입 경로로 연결.
- 큰 모달·키보드: Save/Close/Cancel을 본문 맨 끝에 숨기지 않음.
- 시각적 정체성: 차분하고 정보 밀도가 적절한 개인 기록 도구; 블랙리스트의 의미색 외에 과도한 브랜드 색 반복 금지.
- 언어: 개인의 판단임을 분명히 하며 원본 배민의 공식 가게 제재·평가로 혼동하지 않는 표현.
- 가게 이탈·복귀: 데이터는 Room이 원본, 화면 오버레이는 언제든 재구성 가능한 파생 상태.

### 검증 및 출처

- **사용자 확정:** 별도 Android 보조 앱, 비터치 배지, 스크롤 중 숨김, 상세 기록, 공유 링크/직접 등록.
- **실기기 미확인:** 배민 화면별 AccessibilityNodeInfo의 구체적 가게 카드 구조 및 좌표 노출.
- **미승인 제안:** 원본 APK 패치, 비공개 API, OCR, 네트워크 중간 분석. 이번 범위에서 제외.
- 완료 단계는 코드 테스트·빌드·실기기 조작·사용자 체감 평가를 분리한다.

## 1.1.0 사용자 확정 후속 요구
배민 전면에서 서비스 상태 버튼을 항상 제공한다. 식별 불확실 시 직접 등록·진단만 제공하며 즉시 저장을 비활성화한다. 빠른 블랙 등록과 등록 양식 없는 메모를 제공하고, 실패 단계/좌표/매칭/저장 결과를 내부 진단 파일로 연결한다. 원문 수집은 별도 동의한 5분 진단 세션에서만 허용한다. 진단 화면은 기존 중립 표면·작은 상태 텍스트·이벤트 행을 사용하고 필수 내보내기/중지/삭제를 위쪽에 둔다.
