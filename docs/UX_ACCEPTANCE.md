# 핵심 사용자 여정 및 수용 기준

| 맥락 | 사용자 행동 | 완료 조건 |
|---|---|---|
| 권한 미부여 | 앱 실행 후 가게·메모 생성 | 접근성 권한 없이 데이터 관리 가능 |
| 가게 공유 | 배민에서 공유 → 배민 블랙 선택 | URL 수신, ID 있으면 추출, 없으면 수동 입력 |
| 중복 가게 | 같은 shop ID 다시 공유 | 중복 생성 없이 기존 기록 열기 |
| 검색 목록 | 블랙리스트 가게가 보임 | 정확히 식별 가능한 카드에만 배지 |
| 빠른 관성 스크롤 | 목록을 빠르게 이동 | 기존 배지 즉시 사라지고 이전 좌표에 남지 않음 |
| 스크롤 정지 | 약 180ms 정지 | 현재 노드·좌표 기반으로 새 배지 배치 |
| 매칭 불명확 | 같은 상호의 복수 지점 | 잘못된 가게 차단 표시 없음 |
| 상세 화면 | 등록 가게 진입 | 블랙리스트 경고/메모 진입, 이탈 시 제거 |
| 기록 | 추가·수정·삭제, 재방문 | Room에 정확히 지속 |
| 화면 전환 | 홈·잠금·다른 앱 | 오래된 오버레이 즉시 제거 |
| 복원 | 기존 기록이 있는 상태에서 ZIP 가져오기 | 원본 무조건 삭제하지 않고 충돌 처리 |

UI에 기능 버튼이 '존재'하는 것과 긴 메모·키보드·작은 화면에서 실제로 '누를 수 있는 것'은 별도 검증한다.
