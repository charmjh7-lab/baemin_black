# 배민 블랙 검증

1. **모든 push**: Python 사전 점검, 툴링 유닛 테스트(빠르게).
2. **Android 앱 소스 생성 후**: Android debug APK 빌드; 중요한 모델/링크/매칭/Room/스크롤 상태 유닛 테스트.
3. **변경별 최소 회귀:** 공유 링크 파싱; 동일 shop ID 중복 방지; 모호한 이름 자동 매칭 금지; 스크롤 시 배지 제거와 재표시; 데이터 복원 병합.
4. **실기기 별도 검증:** 배민 접근성 노드 트리 노출, 실제 좌표/화면 이동, 스크롤·잠금·다른 앱 전환, 권한 해제, TalkBack 충돌, 기기별 표시 제한.
5. **릴리스:** APK 하나, 패키지 ID·versionCode·서명 검증, 업데이트 설치 호환, Release 자산 URL 확인.

코드 테스트/CI 통과를 실제 기기의 배민 동작 확인으로 표현하지 않는다. 기존 테스트를 임의 변경해 회귀를 숨기지 않는다.
