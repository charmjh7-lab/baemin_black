# visual-quality

1. 자세한 기준은 `docs/DESIGN_SYSTEM.md`에서 확인한다.
2. 블랙리스트는 작고 명료한 금지 배지로 표시하고 원래 가게 카드의 정보와 겹치지 않게 한다.
3. 배지가 스크롤을 억지로 따라다니는 애니메이션을 만들지 않는다.
4. 관리 앱은 검색·상태·메모가 중심이며 불필요한 카드 중첩과 반복 설명을 줄인다.
5. 다크/라이트, 작은 화면, 큰 글자, 키보드/시스템바에서 대비와 조작 도달성을 확인한다.
