# 구현 및 검증 상태

- 1.1.1(6), 기존 applicationId·Room v1·개발 키·가게/메모·백업 경로 보존. 스키마 변경과 데이터 초기화 없음.
- 현재 활성 루트/애플리케이션 창/시스템 전환을 별도로 판정. 배민 이벤트의 출처만으로 활성화하지 않으며 다른 앱 전환 후 지연 콘텐츠 이벤트는 복귀 신호가 될 수 없음. 이탈 시 generation·예약 분석·세 오버레이를 함께 무효화.
- 상태/상세/배지 창은 명시적인 WindowManager 등록 상태를 사용. attach 전에는 재등록하지 않고 updateViewLayout 사용, 미attach 등록 뷰도 제거. 오류에 작업 종류/등록·attach/전면 창/메시지·원인·스택 기록.
- 상세 인식은 기존 점수에 제목 위치·크기·계층/본문 영역/반복 카드·검색 구조를 함께 판단. 탭 문자열 없이도 확인 가능한 상세만 허용. 일반 로그는 후보 근거·노드/좌표만, 원문은 기존 상세 진단 동의·내보내기 선택 경계 내에 보관.
- 공유용 확정 정보는 화면 수명과 분리해 최대 120초, 이탈 후 최대 90초 유지하고 1회 소비. 일반 앱 이탈은 URL-only 보완을 허가하지 않으며, 확인된 공유 선택 화면 또는 즉시 직접 전달만 허용. 새로운 가게 인식 시 교체, 충돌/만료 보류. TEXT/SUBJECT/TITLE/허용 URL/미리보기/최근 정보의 필드별 출처를 기록하고 기존 기록 조회에도 동일 매칭 규칙 적용.
- 전체 이름/분리 지점명/공백·구분 기호/별칭 비교를 동일 기준으로 통합. 부분 문자열 매칭 없음. 고유번호 충돌과 동명이점 모호성은 계속 보류.
- 공유 Intent→파싱/해석→최근 정보→병합→자동입력→조회→저장/미저장 이탈을 trace로 연결. 예외 메시지·원인 필드는 기본값을 둬 이전 JSONL 호환 유지. 기본 ZIP은 원문 스냅샷 제외.
- 로컬 preflight 및 Python 11개 테스트 통과. 단일 목록 카드 오분류 회귀를 수정했고 `e388315`에서 Android 67개 테스트·빌드·기존 개발 인증서 검증 통과. 확정 문맥으로 상세를 인식한 화면에서 클릭 검증도 같은 문맥을 사용하도록 보강했으며, 다른 가게는 ActionTarget으로 계속 거부한다. 이 마지막 보강분은 후속 실행에서 검증한다.
- 실기기 미검증: 수정 후 삼성 기기에서 홈/최근 앱/공유 선택/복귀와 attach 타이밍, 실제 배민 트리의 상세 인식 및 배지 위치, 공유 URL의 실제 응답. 가상 노드/WindowManager 회귀 테스트를 실기기 성공으로 간주하지 않는다.
