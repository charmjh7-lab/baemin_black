# 확정 결정과 미검증 범위

| 상태 | 결정 |
|---|---|
| 사용자 확정 | 원본 배민 APK 수정 없는 독립 Android 앱 |
| 사용자 확정 | 접근성 API 기반 자동 인식, 오버레이 배지 |
| 사용자 확정 | 스크롤 중 배지 숨김, 정지 후 재표시 |
| 사용자 확정 | 블랙리스트·주의·즐겨찾기·가게별 개인 메모 |
| 사용자 확정 | GitHub 저장소 `charmjh7-lab/baemin_black` 사용 |
| 구현 초기값 | Kotlin/Compose/Room, minSdk 26, 앱 ID `com.charmjh7.baeminblack` |
| 구현 초기값 | 정지 판정 180ms; 실제 기기 검증 후 범위 안에서 튜닝 가능 |
| 실기기 미검증 | 배민 앱의 설치 패키지, 접근성 노드 노출, 카드 계층, 공유 URL의 실제 형태 |
| 미구현 | Android 앱 코드, Gradle, 실제 APK, 가게 인식 결과 |

미검증 사실을 확정 완료로 승격하지 않는다. 새 기능의 방향을 변경할 때 사용자 요청을 우선한다.
